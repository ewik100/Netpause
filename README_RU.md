# NetPause — начальный прототип

Прототип Android-приложения для Poco X5 Pro 5G. Пользователь задаёт длительность и включает локальный VPN, который перехватывает IPv4/IPv6 трафик и намеренно не пересылает пакеты.

## Открытие проекта
1. Распакуй архив.
2. В Android Studio выбери **Open** и укажи папку `NetPause`.
3. Дождись синхронизации Gradle.
4. Подключи Poco X5 Pro 5G по USB с включённой отладкой USB.
5. Нажми Run.
6. При первом запуске блокировки Android покажет системный запрос на создание VPN — подтверди его.

## Важно
- Это стартовый MVP, а не готовое приложение для публикации.
- Блокировка работает, пока VPN-сервис активен. Пользователь может отключить VPN в системных настройках или остановить приложение.
- Android может ограничивать фоновые процессы; для надёжной длительной работы нужно отдельно протестировать энергосбережение MIUI/HyperOS.
- Сейчас таймер живёт в процессе сервиса и не восстанавливается после перезагрузки/принудительной остановки.
- Уведомления и разрешения нужно проверить на конкретной версии Android/HyperOS.
- Трафик намеренно отбрасывается, а не анализируется и не отправляется на сервер.
- При проблемах с VPN подключение к интернету может не восстановиться до остановки VPN или перезагрузки телефона. Предусмотрена кнопка снятия блокировки.

## Сборка APK на GitHub
В проект добавлен workflow `.github/workflows/android-build.yml`.
После загрузки проекта в репозиторий с веткой `main` GitHub Actions автоматически соберёт `app-debug.apk`.
APK можно забрать на странице репозитория: **Actions → Build Android APK → последний успешный запуск → Artifacts → NetPause-debug-apk**.
Также сборку можно запустить вручную через **Actions → Build Android APK → Run workflow**.
