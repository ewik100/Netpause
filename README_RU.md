# NetPause 1.1

NetPause — Android-приложение для временного ограничения доступа приложений к интернету с помощью локального VPN-туннеля. Проект рассчитан на Android 8.0 и новее; основное тестовое устройство проекта — POCO X5 Pro 5G.

## Возможности

- Количество запусков блокировки не ограничено.
- Длительность одной сессии — от 1 до 120 минут.
- VPN включается только после явного запуска пользователем.
- При остановке сессии приложение отправляет VPN-сервису явную команду отключения, закрывает TUN-интерфейс, завершает сервис и удаляет его уведомление.
- Плавающее окно работает отдельно и остаётся доступным после остановки VPN.
- После системного перезапуска сервис не создаёт новую блокировку без явно переданной длительности.
- Постоянный список приложений-исключений: выбранные приложения сохраняют интернет, остальные направляются в локальный VPN и блокируются.
- Поиск приложений по названию и имени пакета, отображение иконок.
- Плавающая кнопка NP с перемещением по экрану и запоминанием позиции.
- Раздельные действия: свернуть панель, скрыть плавающее окно, остановить только VPN или полностью выключить NetPause.
- Анимированная визуализация состояния и прогресса таймера.
- Центр разрешений с независимыми действиями, статусами и отдельной инструкцией для POCO.

## Важное поведение VPN

VPN-сервис должен работать только во время сессии, запущенной пользователем. При ручной остановке или окончании таймера приложение закрывает VPN-интерфейс, удаляет постоянное уведомление и завершает VPN-сервис. Плавающее окно управляется отдельным сервисом и не закрывается при остановке VPN.

Приложение не должно автоматически запускать блокировку при перезагрузке или неожиданном восстановлении сервиса. Если Android продолжает показывать VPN как активный после остановки, проверь системные параметры «Всегда включён» и «Блокировать соединения без VPN». Эти защищённые настройки Android нельзя переключать напрямую из приложения.

## Разрешения

- Показ поверх других приложений — нужен для плавающей кнопки.
- Разрешение локального VPN — нужно для блокировки, но само по себе не включает соединение.
- Уведомления — помогают видеть активную сессию и кнопку остановки.
- Исключение из оптимизации батареи и настройки автозапуска POCO — дополнительные параметры фоновой работы.
- Уже выданные разрешения не должны повторно запрашиваться автоматически. Каждый системный экран открывается только по отдельному действию пользователя.

## Данные и приватность

В версии 1.1 нет аккаунтов, собственного сервера, аналитики или отправки истории блокировок. Настройки и список исключений хранятся локально на устройстве. Приложение намеренно отбрасывает пакеты трафика, попавшие в его VPN-туннель; оно не передаёт этот трафик на внешний VPN-сервер.

## Перед распространением

Текущий APK — тестовая debug-сборка, а не подписанный релиз Google Play. Для публичного выпуска отдельно потребуются release-подпись и Android App Bundle, политика конфиденциальности, оформление деклараций VPN и foreground services в Play Console и проверка соответствия актуальным правилам Google Play.

## Обязательные проверки на реальном устройстве

1. Запустить плавающее окно: VPN не должен включаться.
2. Запустить блокировку: должен включиться системный VPN и появиться уведомление блокировки.
3. Остановить блокировку: VPN-соединение должно исчезнуть из активных подключений Android, VPN-уведомление должно пропасть, плавающее окно должно остаться.
4. Несколько раз запустить и остановить блокировку подряд — лимита запусков больше нет.
5. Проверить автоматическую остановку по таймеру.
6. Проверить приложения-исключения отдельно на Wi-Fi и мобильной сети.
7. Проверить скрытие окна, полное выключение и поведение после перезагрузки.

Успешная сборка не заменяет перечисленные проверки на физическом устройстве.
