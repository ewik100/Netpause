# NetPause 1.7

Android-приложение для управления доступом к интернету на устройстве.

- Пакет: `ru.netpause.app`
- Версия: `1.7` (versionCode 14)
- Минимальная версия Android: 8.0 (API 26)
- Сборка: GitHub Actions — модульные тесты, Android lint и debug APK.

Исходный код приложения хранится в каталоге `.ci/` в виде проверяемых частей архива. Workflow собирает архив, сверяет SHA-256, распаковывает исходники, запускает проверки и публикует APK и ZIP-архив полного проекта как артефакты GitHub Actions.

Важно: если в репозитории не настроен постоянный ключ подписи, APK будет подписан временным debug-ключом. Такой APK может не установиться как обновление поверх приложения, подписанного другим ключом.
